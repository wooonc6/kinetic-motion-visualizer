# Kinematic Motion Visualizer

고등학교 물리의 운동학(Kinematics) 개념을 **시간–위치, 시간–속도, 시간–가속도** 그래프와 실시간 시뮬레이션으로 시각화하는 인터랙티브 웹 앱입니다.

원본 프로젝트 [bogyungkim89/kineticmotion](https://github.com/bogyungkim89/kineticmotion)을 기반으로 하되, 그래프 구성과 물리 개념 표현 방식을 전면 재구성했습니다.

## 원본과 달라진 점

원본은 Streamlit 기반 Python 앱으로, 운동마다 단일 그래프(주로 위치만)를 보여주는 구조였습니다. 이 프로젝트는 순수 HTML/JS로 재작성하면서 아래 부분을 바꿨습니다.

**그래프를 3개 동시 표시**

모든 탭에서 시간–위치, 시간–속도, 시간–가속도 그래프를 나란히 보여줍니다. 세 그래프가 함께 보이면 "x-t의 기울기가 v이고, v-t의 기울기가 a"라는 미적분적 관계를 직접 확인할 수 있습니다.

**포물선 운동 분해 탭 — 다중섬광 방식**

교과서에 나오는 다중섬광(스트로보스코프) 사진 방식을 웹으로 구현했습니다. 일정한 시간 간격(Δt)마다의 물체 위치를 점으로 찍어, 수평 간격이 일정하고 수직 간격이 점점 벌어지는 모습을 직접 확인할 수 있습니다. 합성 운동(2D), 수직 성분(자유낙하), 수평 성분(등속운동)을 세 캔버스에 동시 재생합니다.

**시뮬레이션 캔버스 벡터 표시**

물체 위에 속도 벡터와 가속도 벡터를 화살표로 실시간 렌더링합니다. 포물선 분해 탭에서는 합성 속도를 수평(vₓ)·수직(vᵧ) 성분으로 분해해서 점선 화살표로 함께 보여줍니다.

**그래프 해석 문구 동적 업데이트**

슬라이더 조작 시 그래프 아래 설명이 현재 값에 맞게 바뀝니다.

## 탭 구성 및 물리 개념

### 등가속도 직선운동

초기 속도 v₀와 가속도 a를 슬라이더로 조작합니다.

```
x = v₀t + ½at²
v = v₀ + at
v² = v₀² + 2aΔx
```

- x-t: 기울기 = 순간속도. a ≠ 0이면 포물선, a = 0이면 직선.
- v-t: 기울기 = a. 그래프 아래 넓이 = 변위 Δx.
- a-t: 수평선. 등가속도 운동의 정의.

### 자유낙하

초기 높이 y₀를 조작합니다. g = 9.8 m/s²로 고정.

```
y = y₀ − ½gt²      낙하 시간 t = √(2y₀/g)
v = gt              충돌 속도 v = √(2gy₀)
```

- y-t: 아래로 볼록한 포물선. 기울기(속도)가 점점 가팔라집니다.
- v-t: 원점을 지나는 직선. 기울기 = g. 삼각형 넓이 = 낙하 거리.
- a-t: 9.8 m/s²로 완전히 일정.

### 포물선운동

초기 속력 v₀와 발사각 θ를 조작합니다.

```
수평: vₓ = v₀cosθ (등속)      최고점: t = v₀sinθ / g
수직: vᵧ = v₀sinθ − gt        사거리: R = v₀²sin2θ / g
```

- x·y–t: 수평은 직선, 수직은 포물선.
- vₓ·vᵧ–t: vₓ는 수평선(불변), vᵧ는 기울기 −g의 직선. vᵧ = 0이 최고점.
- aₓ·aᵧ–t: aₓ = 0, aᵧ = −g.

### 포물선 운동 분해

교과서의 다중섬광 사진 원리를 인터랙티브하게 재현합니다.

```
수평 간격 Δx = vₓ·Δt     → 일정 (등속)
수직 간격 Δy = ½g(nΔt)²  → 갈수록 증가 (자유낙하)
```

| 캔버스 | 보여주는 것 | 핵심 |
|---|---|---|
| 다중섬광 메인 | Δt 간격 위치 점 + 축 투영 | 수평 등간격 / 수직 증가 간격 한눈에 |
| 합성 운동 | 2D 궤적, vₓ·vᵧ 화살표 분해 | 포물선 = 두 운동의 합성 |
| 수직 성분 | y축만, 점 간격 수치 표시 | 자유낙하와 동일 |
| 수평 성분 | x축만, 등간격 수치 표시 | 등속운동, 가속도 없음 |

섬광 간격 Δt 슬라이더를 줄이면 점이 촘촘해지고, 늘리면 간격 차이가 명확하게 보입니다.

### 등속 원운동

반지름 r, 각속도 ω를 조작합니다.

```
v = rω (접선 방향)        T = 2π/ω
aꜱ = v²/r = ω²r (구심)
```

- x·y–t: x = r·cosωt, y = r·sinωt. 원운동 = 두 방향 단진동(SHM)의 합성.
- vₓ·vᵧ–t: 위치와 90° 위상 앞섬. 속력 크기 rω는 일정.
- aꜱ–t: ω²r로 일정한 수평선. 방향은 항상 중심을 향하며 속도와 수직(90°).
