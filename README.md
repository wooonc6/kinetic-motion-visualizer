## 🎯 프로젝트 소개

`Kinetic Motion`은 고등학교 물리의 **운동학(Kinematics)** 개념을 **시각적으로 이해**할 수 있도록 만든 교육용 웹 시뮬레이터입니다.

### ✨ 특징

- 📍 **위치, 속도, 가속도** - 기본 개념부터 시작
- 🎯 **자유낙하운동** - 중력의 영향을 실시간으로 관찰
- 🏹 **포물선운동** - 수평과 수직 운동의 합성
- ⭕ **등속 원운동** - 회전 운동과 구심력 이해

### 🎮 인터랙티브 기능

- **슬라이더로 값 조정** - 초기 속도, 가속도, 높이 등을 직접 제어
- **실시간 애니메이션** - 물리 공식에 따른 정확한 시뮬레이션
- **그래프 시각화** - 시간에 따른 변화를 그래프로 표시
- **재생/멈추기/초기화** - 자유로운 실험

## 📚 학습 내용

### 1. 위치, 속도, 가속도
```
위치(Position)    = 물체가 지금 어디에 있는가?
속도(Velocity)    = 물체가 얼마나 빠르게 움직이는가?
가속도(Acceleration) = 속도가 얼마나 빠르게 변하는가?
```

### 2. 자유낙하운동
- 중력 가속도: 9.8 m/s²
- 초기 높이에 따른 낙하 시간 계산
- 모든 물체는 같은 속도로 가속된다

### 3. 포물선운동
- 수평: 등속도 운동
- 수직: 자유낙하 운동
- 두 운동의 독립적 합성

### 4. 등속 원운동
- 속도: 항상 원의 접선 방향
- 가속도: 항상 원의 중심을 향함
- 속도와 가속도는 항상 직각(90°)

## 📖 물리 공식

### 등가속도 직선운동
```
위치: x = v₀t + ½at²
속도: v = v₀ + at
가속도: a = constant
```

### 자유낙하 (a = -g)
```
높이: y = y₀ - ½gt²
속도: v = -gt
```

### 포물선운동
```
수평: x = v_x × t
수직: y = y₀ - ½gt²
```

### 등속 원운동
```
각속도: ω = v/r
구심가속도: a_c = v²/r = ω²r
```
